Penerbangan Nusantara is a flight game: fly a turboprop mail plane between Indonesian islands — take off, fly through target rings, deliver mail to three islands and land before the fuel runs out. Fuel and damage turn each sortie into decisions; keyboard and mouse controls, WebAudio engine sounds, all in static files that run offline in a desktop browser.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
